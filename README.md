# 🍗 Chickenji — The Taste of Happiness

Official website for **Chickenji**, a fast food restaurant specialized in broasted chicken and chicken sandwiches.

## 🌐 Live Site
Hosted via GitHub Pages: `https://<your-username>.github.io/chickenji`

## ✨ Features
- Bilingual: **English / Arabic** with full RTL support
- Fully responsive: mobile & desktop
- Interactive menu with category filters
- Embedded real logo, interior photo, and full menu images
- Direct links: Phone, WhatsApp, Instagram, Facebook

## 📁 Structure
```
chickenji/
└── index.html   ← entire site (self-contained, no dependencies)
```

## 🚀 Deploy on GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, `/ (root)` folder
4. Save → your site is live in ~60 seconds
